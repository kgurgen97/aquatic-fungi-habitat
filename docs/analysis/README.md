# Analysis notes

This directory preserves detailed result reports, including analyses that did not support their preregistered predictions or were subsequently superseded. The final numerical claims and captions belong to the manuscript and supplementary tables.

- `BENCHMARK_RESULTS.md`: first estimator benchmark, subsequently rejected
- `BENCHMARK2_RESULTS.md`: corrected benchmark
- `DEPTH_LADDER_RESULTS.md`: controlled depth analysis
- `NEON_RESULTS.md`: external dataset checks
- `OCCUPANCY_RESULTS.md`, `PREVALENCE_RESULTS.md`: detection and occupancy checks
- `SWEEP_RESULTS.md`: parameter-space sweep
- `EUK_RESULTS.md`, `ZOOSPORIC_RESULTS.md`: biological comparisons
- `METAPR2_RESULTS.md`: suitability assessment of another dataset

Frozen `*PLAN*.md` files remain at the repository root to preserve scripts and hashes.
